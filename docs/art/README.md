# FRONTIER art

Concept and cover art for FRONTIER. None of it is loaded by the game: the in-game ships are
low-poly models built by `tools/shipgen` and rendered to PS1 sprites, using these pictures as
reference.

| Path | What it is |
| --- | --- |
| `ships/` | AI-generated concept art for the ship classes: civilian ships, UFS and FSA navy hulls, and the Veyr. The full write-up of every class is in [`../Frontier_Ship_Classes.odt`](../Frontier_Ship_Classes.odt) |
| `cover/cover_original.png` | The AI-generated cover painting (1254 px square) |
| `cover/cover_with_logo.png` | The same painting with the game's logo in place of the painted title: the front of the jewel case manual |
| `cover/wayfarer_concept.jpg` | The concept picture of Chad Beefsteel's ship that the in-game Wayfarer is based on |
| `logo_print.png` | The title logo at print size (1901 px wide) with a transparent background, made by `tools/artgen/logo_print.py` from the same drawing as the in-game logo |

The jewel case manual, tray card and disc label were designed on a Claude design canvas and are
not in this repository.
